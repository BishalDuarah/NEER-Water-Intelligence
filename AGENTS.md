# AGENTS.md — NEER Water Intelligence

Project context for Team Falcons' TigmaMinds Academy Hackathon 2026 entry.
Decision-support platform: detect/correlate/assess/recommend on simulated water data.

## Hard constraints (do not violate)

- **No autonomous control.** System is decision support only. Never control physical water infrastructure.
- **No LLM for numbers.** Anomaly detection and risk scoring are deterministic/statistical (scikit-learn only where it genuinely helps). LLM never computes anomalies or arbitrary risk scores.
- **LLM gets structured context, not raw sensor streams.** Feed structured incident evidence; require every AI recommendation to trace back to that evidence.
- **No hardcoded secrets.** Never commit `.env` or credentials. Keep runnable locally without external services where possible.
- **Risk scoring formula must live in code and be documented**, not generated by the LLM.

## Stack

- Frontend: React + Vite + Tailwind CSS + TypeScript
- Backend: Python + FastAPI, SQLAlchemy (DB access), Pydantic (API boundaries), PostgreSQL
- Intelligence: Python statistical/ML modules, LLM API only for structured incident explanation & response recommendations
- Comms: REST; WebSocket/SSE only if genuinely required

## Architecture rules

- Keep intelligence modules independently testable and separate from LLM reasoning.
- Keep business logic out of frontend components.
- Keep DB access out of route handlers where practical.
- Type hints everywhere; handle errors explicitly.
- Maintain tests for intelligence calculations and critical API behavior.

## Demo that must work end-to-end (priority over extras)

Normal network → inject Zone B incident (pressure drop, abnormal flow/consumption, rising complaints) → detect anomalies → correlate signals → generate incident → calculate risk → generate AI brief → recommend actions → operator assigns → resolve.
Incident lifecycle: Detected → Investigating → Assigned → Resolved.
